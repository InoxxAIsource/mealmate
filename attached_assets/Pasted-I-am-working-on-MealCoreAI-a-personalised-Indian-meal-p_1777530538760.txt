FEATURE 2 — Water Intake Tracker
Add a water intake tracker to the app dashboard. This is a very simple but important feature — many Indian users with PCOS and diabetes do not drink enough water, and tracking it daily builds a healthy habit.
The tracker should show the user how many glasses of water they have drunk today versus their daily goal. The goal should be personalised — PCOS and diabetes users get a goal of 10 glasses because hydration directly helps with insulin and hormone regulation. Pregnancy users also get 10 glasses. Everyone else gets 8 glasses as the default.
The UI should show a row of water drop icons. Filled blue drops represent glasses already consumed, and grey drops represent the remaining goal. The user taps a drop to add one glass. They can also remove a glass if they made a mistake. Show the count clearly as text, for example "6 out of 8 glasses today." When they reach their goal, show a congratulations message that mentions their health condition specifically.
Save each day's water log separately so the user can see yesterday's count as a reference below today's tracker.
Also add a push notification that fires at 2 PM if the user has consumed fewer than 4 glasses by that time. The notification message should say something like "Don't forget to drink water — you have only had 3 glasses today, your goal is 8."
Place the water tracker widget on the main dashboard below the meal plan cards.

FEATURE 3 — Step-by-Step Recipes for Every Dish
Right now the app tells users what to eat — for example "Breakfast: Ragi Dosa" — but does not tell them how to make it. Many users, especially younger users or users from a different region than the dish, will not know how to cook an unfamiliar dish. Adding recipes solves this and keeps users in the app longer.
Every dish in the database should have a recipe page. The recipe page should show the dish name, a list of all ingredients with exact quantities in Indian measurements like cups, tablespoons, and teaspoons, and numbered cooking steps written in simple language that a home cook can follow in 20 to 25 minutes. Also show a chef tip which is one practical piece of advice like "soak ragi overnight for a better texture." Show a health note that explains in one sentence why this dish is good for the user's health condition.
Use the OpenAI API to automatically generate recipe content for all dishes in the database. Write a seed script that loops through every dish, sends a prompt to OpenAI asking for ingredients, steps, chef tip, and health note, and saves the result to the database. The generated content should use Indian ingredients only — no Western substitutes. Steps should be simple and short, maximum two sentences each.
From the meal plan view, every dish card should have a small "View Recipe" button or link that takes the user to the recipe page for that dish.
Also generate Hindi versions of all recipe content at the same time — Hindi ingredients list, Hindi steps, Hindi chef tip — so the recipe page works in both English and Hindi without needing a separate translation step later.
